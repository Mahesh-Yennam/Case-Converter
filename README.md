# Case Converter, Text Cleaner & Slugifier — Gamility Tools

A modern, fast, and 100% private client-side text transformer and formatting utility. Converts text effortlessly across all major programming and typography cases, scrubs extra whitespaces, filters duplicate lines, and generates clean SEO-friendly URL slugs.

---

## 🌟 Features & Highlights

- **🔤 Comprehensive Case Styles:**
  - `UPPERCASE` — ALL CAPITAL LETTERS
  - `lowercase` — all lowercase letters
  - `Title Case` — Smart APA / Chicago style capitalization (keeps articles and prepositions lowercase)
  - `Sentence case` — Capitalizes the initial character of each sentence
  - `camelCase` — Lowercase first word, capitalized subsequent words (e.g., `myVariableName`)
  - `PascalCase` — Capitalized first letter for each word (e.g., `MyClassName`)
  - `snake_case` — Underscore separated lowercase (e.g., `database_column_name`)
  - `kebab-case / slugify` — Hyphen separated lowercase clean URLs (e.g., `my-article-slug`)
  - `CONSTANT_CASE` — SCREAMING_SNAKE_CASE for environment variables & constants
  - `dot.case` — Period separated lowercase (e.g., `package.module.name`)
  - `path/case` — Slash separated filesystem paths
  - `aLtErNaTiNg cAsE` — SpongeBob sarcastic alternating case
  - `InVeRsE cAsE` — Flips lowercase to uppercase and uppercase to lowercase
- **🧹 Power Text Cleaners:**
  - Strip redundant whitespace and normalize spaces.
  - Remove empty and blank lines.
  - Remove duplicate lines.
  - Strip HTML and XML markup tags.
  - Remove special punctuation and symbols.
  - Alphabetical line sorting (A → Z and Z → A).
  - Reverse characters and reverse words order.
- **📊 Real-Time Metrics:** Live count of total characters (with & without whitespace), word count, sentence count, line count, and average word length.
- **⚡ Interactive Live Cards:** Preview all transformations at a glance and copy any converted format with 1-click.
- **🔒 100% Client-Side Privacy:** Zero server transmissions. All string manipulation executes strictly in your browser's local memory.

## 🚀 Quick Start

### Local Preview
Open `index.html` directly in any modern browser:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

Or serve via any static HTTP server:
```bash
npx serve .
```
